## 一.基础知识

内存大小转换:存储器容量指存储器中所包含的字节数，通常用KB、MB、GB、TB和PB作为存储器容量单位。它们之间的关系为:
1KB=1024B 1MB=1024KB 1G=1024MB 1TB=1024GB 1PB=1024 TB。

输入设备是外界向计算机传递信息的装置。
常见的输入设备主要为：光电笔、条形码扫描器、键盘、鼠标、触摸屏、图像扫描仪、麦克风、游戏手柄等。

输出设备的作用是将计算机中的数据信息传送到外部媒介，并转化成某种为人们所认识的变现形式。
常见的输出设备主要为：显示器、打印机、音响、投影仪等。

操作系统是计算机系统的控制和管理中心，从资源角度来看，它具有处理机、存储器管理、设备管理、文件管理等4项功能。
常用的系统有DOS操作系统、WINDOWS操作系统、UNIX操作系统和Linux、Netware、鸿蒙等操作系统。

数据库管理系统有组织地、动态地存贮大量数据，使人们能方便、高效地使用这些数据。
数据库管理系统是一种操纵和管理数据库的大型软件，用于建立、使用和维护数据库。
Foxpro，Access，Oracle，Sybase，DB2和Informix则是数据库系统。

应用软件（Application）是和系统软件相对应的，是用户可以使用的各种程序设计语言，以及用各种程序设计语言编制的应用程序的集合，分为应用软件包和用户程序。
应用软件一般分为两类:一类是为特定需要开发的实用型软件，如会计核算软件、订景系统、工程预算软件和教育辅助软件等；另一类是为了方便用户使用计算机而提供的一种工具软件，如用于文字处理的Word、用于辅助设计的AutoCAD及用于系统维护的瑞星杀毒软件等。

计算机语言(机器语言、汇编语言和高级语言。):<br/>
机器语言：
写出一串串由"0"和"1"组成的指令序列交由计算机执行，这种计算机能够认识的语言，就是机器语言。机器语言，是第一代计算机语言。<br/>
汇编语言：
用一些简洁的英文字母、符号串来替代一个特定的指令的二进制串，比如，用"ADD"代表加法，"MOV"代表数据传递等等，这样一来，人们很容易读懂并理解程序在干什么，纠错及维护都变得方便了，这种程序设计语言就称为汇编语言，即第二代计算机语言。<br/>
计算机高级语言(我们学的C++就属于这个):是一种编程语言，它提供了比机器语言（即计算机的硬件可以直接理解的二进制指令）更高层次的抽象。高级语言的设计是为了让程序员更容易编写、阅读和维护代码，因为它们使用更接近自然语言的语法结构，并且通常具有丰富的数据类型和操作符。
高级语言有：BASIC（True basic、Qbasic、Virtual Basic）、C、C++、PASCAL、FORTRAN、智能化语言（LISP、Prolog、CLIPS、OpenCyc、Fazzy）、动态语言(Python、PHP、Ruby、Lua)等等。- 高级语言源程序可以用解释、编译两种方式执行。通常用后一种。


## 二.简单语句
### 1.简单语句
#### 1.1 赋值语句
赋值语句用于给变量赋值。在C++中，赋值操作符是等号=。赋值语句的一般形式是：
```C++
variable = expression; //变量=值；
```
其中 variable 是一个有效 ( 满足命名规则 ) 的变量名，而 expression 可以是一个常量、另一个变量或是一个表达式。例如：
```C++
int a,b,c;
a = 5; // 将整数5赋值给变量a
b = a; // 将变量a赋值给变量b
c = a + b; // 将变量a和变量b的和赋值给变量c
```
#### 1.2 cin 语句与scanf 语句
cin 和 scanf 都是用来从标准输入（通常是键盘）读取数据的函数，但它们属于不同的库和语法风格。
cin：这是C++标准库的一部分，使用流操作符>>来读取数据。
```C++

using namespace std;    // 别忘记啦！！！
```

```C++

...int main 那些老师就不写了
```

以下是 scanf 支持的一些常见格式化字符串：<br/>

%lf：用于读取双精度浮点数。<br/>
%c：用于读取单个字符。<br/>
%s：用于读取字符串（以空格为结束标志）。<br/>

### 4.程序结构
#### 4.1 分支结构
就是if和switch语句嘛，if的话他们也就if、else两关键字，没了。脑子里看到题目知道他的执行会执行到哪去，这一块儿就能拿满分
```C++
if (condition1) {
    // 条件1为真时执行这段代码
} else if (condition2) {
    // 条件2为真时执行这段代码
} else {
    // 没有条件为真时执行这段代码
}
```
switch很简单的，唯一要记住的，就是他的格式，其他的就是一个公式一样的，不过考的也少.
```C++
switch (expression) {
    case value1:
        // 当 expression 的值等于 value1 时执行这段代码
        break;
    case value2:
        // 当 expression 的值等于 value2 时执行这段代码
        break;
    default:
        // 当 expression 的值不匹配任何 case 时执行这段代码
}
```
这个引申的还有三目运算符<br/>
```C++
condition ? expression_if_true : expression_if_false
语法解释：
condition：一个表达式，其结果必须可以转换为布尔值（true 或 false）。
expression_if_true：如果 condition 的结果为 true，则计算并返回这个表达式的值。
expression_if_false：如果 condition 的结果为 false，则计算并返回这个表达式的值。
实例：
int a = 10, b = 20;
int max = (a > b) ? a : b;
cout  << max << endl; //20
```
逻辑解释：在这个例子中，(a > b) ? a : b 是一个三目运算符表达式。它检查 a 是否大于 b，如果是，则将 a 的值赋给 max；否则，将 b 的值赋给 max，结果输出20。

#### 4.2.1 while、do while循环
```C++
1.while 循环：先检查条件，如果条件为真，则执行循环体内的代码。每次迭代后重
新检查条件，直到条件为假。
while (condition) {
    // 只要 condition 为真就一直执行这段代码
}

2.do-while 循环：至少执行一次循环体内的代码，然后检查条件，如果条件为真则
继续执行循环。
do {
    // 先执行这段代码
} while (condition);
```

#### 4.2.3 continue，break
break 和 continue 是C++中用于控制循环执行流程的关键字。
```C++
1.break
作用：立即退出最内层的循环（如 for、while 或 do-while），并继续执行循环之后的代码。
适用场景：当你想要提前结束一个循环时使用，比如在找到了所需的元素后不再需要继续迭代。

 for (int i = 0; i < 10; ++i) {
        if (i == 5) {
            break; // 当 i 等于 5 时，跳出循环
        }
        cout << "i = " << i << endl;
    }

输出结果:
i = 0
i = 1
i = 2
i = 3
i = 4
```
自己要在脑子中明白，为什么最后一次不执行!
```C++
continue
作用：跳过当前循环体中的剩余部分，并直接开始下一次循环的迭代。对于 for 循环，这
意味着会检查条件表达式并更新计数器；对于 while 和 do-while，则会重新评估条件
表达式。
适用场景：当你想要跳过某些特定的迭代，但仍然希望继续执行循环的其余部分时使用。
示例：
for (int i = 0; i < 10; ++i) {
        if (i % 2 == 0) {
            continue; // 当 i 是偶数时，跳过本次循环剩下的部分
        }
        cout << "i = " << i << endl;
    }

输出结果:
i = 1
i = 3
i = 5
i = 7
i = 9
```
