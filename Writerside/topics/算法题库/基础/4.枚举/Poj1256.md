# Anagram

Southwestern European Regional Contest 1995

## Problem
Write a program that, given a set of letters, generates all possible words that can be formed from those letters.
- For example, given the word "abc", the program should output the six different permutations "abc", "acb", "bac", "bca", "cab", "cba".
- If the input word contains duplicate letters, the output should not contain duplicate words, and should be sorted in lexicographical order.

## Input
1. The first line contains an integer representing the number of words that follow.
2. Each subsequent line contains a word composed of uppercase and lowercase letters (A-Z), case-sensitive, with a length less than 13.

## Output
For each input word, output all possible permutations of its letters (without duplicates), sorted in lexicographical order.  
**Lexicographical Order Rule**: Uppercase letters come before their lowercase counterparts. For example, `'A'<'a'<'B'<'b'<...<'Z'<'z'`.

## 问题描述
编写一个程序，生成给定字母集合的所有可能排列组合形成的单词。
- 示例：给定单词 "abc"，程序应输出 "abc"、"acb"、"bac"、"bca"、"cab"、"cba" 这六种不同排列。
- 输入单词中可能包含重复字母，要求输出不重复的单词，且按字母升序排列。

## 输入格式
1. 首行输入一个整数，表示后续单词的数量。
2. 接下来每行输入一个单词，由大写或小写字母（A-Z）组成，大小写视为不同字符，单词长度小于13。

## 输出格式
对每个输入单词，输出其所有可能的字母排列组合（不重复），按字母升序排列。  
**字母顺序规则**：大写字母优先于对应小写字母，例如 `'A'<'a'<'B'<'b'<...<'Z'<'z'`。
