# A - Tiny Arithmetic Sequence
## 题目信息
- **时间限制**：2 秒
- **内存限制**：1024 MiB
- **分值**：100 分

## 问题描述
给定一个长度为 3 的数列 $A=(A_1,A_2,A_3)$，判断是否可以通过适当排列其元素，使其成为等差数列。也就是说，能否重新排列 $A$ 中的元素，使得 $A_3 - A_2 = A_2 - A_1$。

## 约束条件
- $1 \leq A_i \leq 100$
- 输入的所有值都是整数

## 输入格式
输入通过标准输入按以下格式给出：
$A_1$ $A_2$ $A_3$

## 输出格式
如果可以将 $A$ 的元素重新排列成等差数列，输出 "Yes"；否则输出 "No"。

## 样例输入与输出
| 样例中的A | 输出 |
| :--------: | :----: |
|  (5,1,3)   |  Yes   |
|  (1,4,3)   |   No   |
|  (5,5,5)   |  Yes   |
