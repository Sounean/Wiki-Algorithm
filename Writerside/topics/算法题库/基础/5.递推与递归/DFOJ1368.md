# DFOJ1368 - 蜜蜂路线

## 题目描述

一只蜜蜂在下图所示的数字蜂房上爬动,已知它只能从标号小的蜂房爬到标号大的相邻蜂房,现在问你:蜜蜂从蜂房
M开始爬到蜂房N，1≤ M < N <= 100，有多少种爬行路线?

![](https://oj.czos.cn/uploads/20211116/a25db1cf00cff55b356c978796402111.png)

## 输入格式

输入 M，N 的值。(1≤ M <N≤ 100)

## 输出格式

爬行有多少种路线。

## 输入输出样例 1

### 输入 

```
1 14
```

### 输出 

```
377
```

## 输入输出样例 2

### 输入

```
1 100
```

### 输出

```
354224848179261915075
```
