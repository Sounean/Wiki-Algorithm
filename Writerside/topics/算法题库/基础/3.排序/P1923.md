# P1923

求第 k 小的数
(用[用快排实现](Quick-Sort.md))

## 1.题目描述
输入 n（1≤n<5000000 且 n 为奇数）个数字$a{i}$（1≤$a{i}$<$10^9$），输出这些数字的第 k 小的数。最小的数是第 0 小。

## 2.输入输出
### 2.1.输入格式
第一行有两个整数，分别表示 n 和 k。

第二行有 n 个整数，第 i 个数表示$a{i}$。

### 2.2.输出格式
一个整数，表示第 k 小的数。

#### 2.3.1测试集1
#### 输入
```C++
5 1
4 3 2 1 5
```

### 输出
```C++
2
```
