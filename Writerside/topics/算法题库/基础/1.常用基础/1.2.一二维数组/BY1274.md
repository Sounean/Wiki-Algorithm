# BY1274 平均分

## 题目描述
请从键盘读入一个整数n(n <= 100)，代表一个班级同学的人数，然后读入 n 个人的语文、数学、英语成绩。
请求出这 n 个人的语文、数学、英语三科成绩的平均分分别是多少，结果保留 1 位小数。

## 输入格式
第 1行:一个整数 n，代表班级的人数。
第 2 行:第n+1行，输入n个同学的语文、数学、英语成绩，每行输入一个同学的成绩，成绩用空格隔开!

## 输出格式
输出语文、数学、英语三科的平均成绩，分别用空格隔开，平均成绩保留 1 位小数！

## 输入输出样例

### 输入 
```C++
2
100 99 98
99 98 97
```

### 输出 
```C++
99.5 98.5 97.5
```
