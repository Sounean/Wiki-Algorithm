# P5721 【深基4.例6】数字直角三角形

## 题目描述

给出 $n$，请输出一个直角边长度是 $n$ 的数字直角三角形。所有数字都是 $2$ 位组成的，如果没有 $2$ 位则加上前导 $0$。

## 输入格式

输入一个正整数 $n$。

## 输出格式

输出如题目要求的数字直角三角形。

## 输入输出样例

### 输入 

```
5
```

### 输出  

```
0102030405
06070809
101112
1314
15
```

## 说明/提示

数据保证，$1\le n\le13$。

printf("%02d" , 整型变量a)  这个代码的效果是如果变量a小于2位，则它的前面用0去补齐，

例:int a = 2;printf("%02d" ,a); 效果为输出"02" ;

例:int a = 12;printf("%02d" ,a); 效果为输出"12" ;

这题如果没思路，按照上次教的，把问题拆分成子问题，这题先实现可以输出那么多行的，再来实现每行里面要去实现的内容。
