<!-- math: true -->

【深基15.例2】寄包柜

## 1.题目描述
超市里有 n(1≤n≤$10^5$) 个寄包柜。每个寄包柜格子数量不一，第 i 个寄包柜有$a_i$
(1≤$a_i$≤$10^5$) 个格子，不过我们并不知道各个$a_i$的值。对于每个寄包柜，格子编号从 1 开始，一直到$a_i$。现在有 q(1≤q≤$10^5$) 次操作：

   ● 1 i j k：在第 i 个柜子的第 j 个格子存入物品 k(0≤k≤$10^9$)。当 k=0 时说明清空该格子。

   ● 2 i j：查询第 i 个柜子的第 j 个格子中的物品是什么，保证查询的柜子有存过东西。


已知超市里共计不会超过$10^7$个寄包格子，$a_i$是确定然而未知的，但是保证一定不小于该柜子存物品请求的格子编号的最大值。当然也有可能某些寄包柜中一个
格子都没有。

## 2.输入输出
### 2.1.输入格式
第一行 2 个整数 n 和 q，寄包柜个数和询问次数。

接下来 q 个行，每行有若干个整数，表示一次操作。

### 2.2.输出格式
对于查询操作时，输出答案，以换行隔开。

### 2.3.输入输出样例

#### 2.3.1测试集1
#### 输入
```C++
5 4
1 3 10000 118014
1 1 1 1
2 3 10000
2 1 1
```

### 输出
```C++
118014
1
```

### 3.C++解法
思路：有了前面的模拟算法思维，这里直接会往构建一个二维数组方面想，但是真要构建的话才会发现问题，因为如果要搞一个
$10^5$*$10^5$的int数组，直接需要分配4*$10^{10}$Byte内存空间，大约40G，闹呢！？

那么这题其实他就不想让你用固定长度的数组去解决！重点其实就是想让用[可变长数组vector](vector-Basic.md)(或者map也可以)来处理该问题。

了解到这点，这题基本就AC了。


```C++
#include <iostream>
#include <vector>

using namespace std;

int n, q;

int deskNo,boxNo;   // deskNo：第几个柜子,boxNo：柜子的第几个格口
int main(){
    cin >> n >> q;
    vector<vector<int>> locker(n+1);
    while(q--){
        int type;   // 操作类型
        cin >> type;
        if(type==1){
            int nums;   // 存放夺少东西
            cin >> deskNo >> boxNo >> nums;
            if(locker[deskNo].size() < boxNo+1){
                locker[deskNo].resize(boxNo+1);
            }
            locker[deskNo][boxNo] = nums;
        }else{
            cin >> deskNo >> boxNo;
            cout << locker[deskNo][boxNo] << endl;
        }
    }

    return 0;
}
```
