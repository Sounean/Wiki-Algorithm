# P1518 [USACO2.4] 两只塔姆沃斯牛 The Tamworth Two

## 1.题目描述
建议1刷思考时间:15min<br/>
建议1刷思考+做题时间:20min

两只牛逃跑到了森林里。Farmer John 开始用他的专家技术追捕这两头牛。你的任务是模拟他们的行为（牛和 John）。

追击在 10×10 的平面网格内进行。一个格子可以是：一个障碍物，两头牛（它们总在一起），或者 Farmer John。两头牛和 Farmer John 可以在同一个格子内（当他们相遇时），但是他们都不能进入有障碍的格子。

一个格子可以是：
- `.` 空地；
- `*` 障碍物；
- `C` 两头牛；
- `F` Farmer John。

这里有一个地图的例子：

```text
*...*.....
......*...
...*...*..
..........
...*.F....
*.....*...
...*......
..C......*
...*.*....
.*.*......
```

牛在地图里以固定的方式游荡。每分钟，它们可以向前移动或是转弯。如果前方无障碍（地图边沿也是障碍），它们会按照原来的方向前进一步。否则它们会用这一分钟顺时针转 90 度。 同时，它们不会离开地图。

Farmer John 深知牛的移动方法，他也这么移动。

每次（每分钟）Farmer John 和两头牛的移动是同时的。如果他们在移动的时候穿过对方，但是没有在同一格相遇，我们不认为他们相遇了。当他们在某分钟末在某格子相遇，那么追捕结束。

读入十行表示地图。每行都只包含 10 个字符，表示的含义和上面所说的相同。保证地图中只有一个 `F` 和一个 `C`。`F` 和 `C` 一开始不会处于同一个格子中。

计算 Farmer John 需要多少分钟来抓住他的牛，假设牛和 Farmer John 一开始的行动方向都是正北（即上）。 如果 John 和牛永远不会相遇，输出 0。

## 2.输入输出
### 2.1.输入格式

输入共十行，每行 10 个字符，表示如上文描述的地图。

### 2.2.输出格式

输出一个数字，表示 John 需要多少时间才能抓住牛们。如果 John 无法抓住牛，则输出 0。

### 2.3.输入输出样例

### 输入 

```
*...*.....
......*...
...*...*..
..........
...*.F....
*.....*...
...*......
..C......*
...*.*....
.*.*......
```

### 输出 

```
49
```


## 3.C++解法

思路：<br/>
1.(★★☆☆☆)地图可以做成一个二维数组存起来，每一次农夫和牛在地图哪里，其实就是在二维数组哪个坐标上；<br/>
2.(★★☆☆☆)之后农民和牛的移动可以理解成一个二维数组，第一位存的未来要修改的x坐标的差值，第二位存的未来要修改的y坐标的差值；<br/>
3.(★★☆☆☆)能否碰面其实就是看农夫和牛的位置坐标能否在未来某一个时刻相同了；<br/>
4.(★★☆☆☆)他们一直走，那肯定用的while(1)循环方便了；<br/>
5.(★★★★★)如何解决"判断他们不会相遇"问题，可以先做保留先不去管，上面做出来就不错了，如何解决可以看下面题解。<br/>

题解:
1.因为农夫和牛的行为和属性是统一的"按规律移动"、"坐标"  而后在代码中肯定要重复多次对这两个进行操作，那么势必会带来代码上的冗杂，导致可读性差，
用结构体的方式，各自结构体的对象，单一去管理负责这两个状体，可读性就上来了;<br/>
2.因为碰到墙壁和障碍物后的移动，是一个规律性，周期性的转动状态，故可以用一个数组去表示；而后再用求余去表示当前是使用第几个状态，方便状态的管理;<br/>
3.因为每次对移动后的坐标都要做一次预测是否碰到墙壁和障碍物，if语句既要对农民判断，又要对牛判断，而判断的逻辑又是一致的，所以可以将其判断抽离成一个
函数，且将农民或者牛的坐标弄成参数传进去，就统一管理该判断了。简洁了代码;<br/>
4.如何去判断是否他们永远无法碰到，其实要理解成：我们要把每一刻，农民和牛当前的坐标和要移动的状态抽象成一个"场景"保存下来，如果未来一段时间
一直没发生碰撞，且在某一刻该 "场景"复现了，就说明从保存该场景的那一刻到场景复现的这一刻，中间这一段的变化是一个周期，他们会循环往复下次，不会碰到。<br/>
再转换成编程语言其实就很多种了，下方是做一个多维数组，该多维数组初始状态均为false表示，然后将某一个场景存到多维数组中，将对应的值设为true，那么下次
再修改数组前先判断该数组的对应你要存的值是否为true，true则代表之前已经有相同的场景被保存了，即产生循环了，他们不会碰面了。<br/>
加入上述转换成编程语言的思路没法理解，可以先从二维开始理解，我要存入一堆类似(x,y)的坐标，如(1,0),(2,0),(1,0)，那么我就创建出来一个int visited[2][2]={false}
的数组，然后我要存(1,0)坐标进去，就是"visited[1][0]=true;",未来第二个(1,0)存入前，会进行一次判断，"if(visited[1][0])"，答案自然是true，即之前
已经存入了,产生重复了。<br/>

```C++
如果数组方式嫌麻烦，还可以做一个set<string> visited集合来存储他们的状态，你就将他们的场景拼接成string存进去，未来就判断该集合中有没有存入过即可。
```


```C++
#include <iostream>
using namespace std;

// 农夫和牛的实体类
struct Bean{
    int currentDirIndex = 0;
    int currentPoint[2];
};

// 移动的偏移量
int offset[4][2] = {{-1,0},  // 北（上）
                    {0,1},   // 东（右）
                    {1,0},   // 南（下）
                    {0,-1}}; // 西（左）
                    
// 地图
char map[10][10];

// 记录历史状态，避免无限循环
bool visited[10][10][10][10][4][4] = {false};
int cnt = 0;

// 检查是否可以移动到指定位置的函数
bool canMove(int x, int y) {
    return x >= 0 && x < 10 && y >= 0 && y < 10 && map[x][y] != '*';
}

int main(){
    Bean F = Bean();
    Bean C = Bean();

    for(int i=0; i<10; i++){
        for (int j = 0; j < 10; ++j) {
            cin >> map[i][j];
            if(map[i][j] == 'F'){
                F.currentPoint[0] = i;
                F.currentPoint[1] = j;
            }else if(map[i][j] == 'C'){
                C.currentPoint[0] = i;
                C.currentPoint[1] = j;
            }
        }
    }

    // 检查初始状态是否已经相遇
    if(F.currentPoint[0] == C.currentPoint[0] && F.currentPoint[1] == C.currentPoint[1]){
        cout << 0 << endl;
        return 0;
    }

    while (true){
        // 移动F
        int nextFx = F.currentPoint[0] + offset[F.currentDirIndex][0];
        int nextFy = F.currentPoint[1] + offset[F.currentDirIndex][1];

        if (!canMove(nextFx, nextFy)) {
            // 不能前进，顺时针转90度
            F.currentDirIndex = (F.currentDirIndex + 1) % 4;
        } else {
            // 正常前行
            F.currentPoint[0] = nextFx;
            F.currentPoint[1] = nextFy;
        }

        // 移动牛
        int nextCx = C.currentPoint[0] + offset[C.currentDirIndex][0];
        int nextCy = C.currentPoint[1] + offset[C.currentDirIndex][1];

        if (!canMove(nextCx, nextCy)) {
            // 不能前进，顺时针转90度
            C.currentDirIndex = (C.currentDirIndex + 1) % 4;
        } else {
            // 正常前行
            C.currentPoint[0] = nextCx;
            C.currentPoint[1] = nextCy;
        }

        cnt++;

        // 检查是否相遇
        if(F.currentPoint[0] == C.currentPoint[0] && F.currentPoint[1] == C.currentPoint[1]){
            cout << cnt << endl;
            return 0;
        }

        // 检查当前状态是否已访问过（在移动之后检查）
        int fx = F.currentPoint[0], fy = F.currentPoint[1];
        int cx = C.currentPoint[0], cy = C.currentPoint[1];
        int fd = F.currentDirIndex, cd = C.currentDirIndex;
        
        if (visited[fx][fy][cx][cy][fd][cd]) {
            cout << 0 << endl;  // 永远不会相遇
            return 0;
        }
        
        // 标记当前状态为已访问
        visited[fx][fy][cx][cy][fd][cd] = true;
    }
    return 0;
}
```
