# 4.插入排序

上面举的是刚玩扑克时候的排牌顺序，而实际上玩久了，不会这么搞，因为每排一次都要在无序的牌堆中从头看到尾，太累了，自然而然有另一种下意识的方式:

摸到第一张后，就以第一张为标准，对于第二张，直接对比第一张的大小，并进行插入；对于第三张，直接在已经排列好大小的最左侧牌堆中比较大小，进行插入；
后面以此类推，直到排完。

那这个和原来的有啥区别？有很大区别：原先玩牌新手下意识用的“选择排序”，每次都要将一张牌，在剩下无序的牌堆中从头看到尾，一张不落的看完，才能挑出最大的，再放到有序的牌堆中；<br/>
<warning>记住，是每次对比，要一张不落的对比过去</warning>
而老手用的"插入排序"，不是从无序的牌堆中找最大的，而是抽出一张后，往有序的牌堆中进行对比，那么就会出现这么一个情况，一旦出现有个位置，他放进去后依然大小有序，
那么就可以停止继续比较了，他就插入那里，节省掉本次后面进行对比大小的时间！
<note>一旦某个位子是可以供他放进去的，那么就不需要再对比下去了</note>

这就是他们的区别。

## python写法
```Python
def insert_sort(nums):
    """
    插入排序：从第二个数字开始从后往前寻找每一个数字应该插入的正确位置
    时间复杂度：平均情况：O(n^2),最坏情况(数组完全逆序,每个元素都要与前面所有元素比较)：O(n^2),最好情况(数组有序)：O(n)
    空间复杂度：O(1)
    """
    n = len(nums)
    for i in range(1, n):
        current_value = nums[i]
        pos = i  # 记录正确位置
        while pos > 0 and nums[pos - 1] > current_value:
            nums[pos] = nums[pos - 1]
            pos -= 1
        nums[pos] = current_value
    return nums
```

## c++写法
```C++
#include <iostream>
#include <vector>
using namespace std;

// 基础插入排序
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    
    // 从第二个元素开始（第一个元素视为已排序）
    for (int i = 1; i < n; i++) {
        int key = arr[i];  // 当前要插入的元素
        int j = i - 1;
        
        // 将比key大的元素向后移动
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        
        // 插入key到正确位置
        arr[j + 1] = key;
    }
}
```

## 复杂度分析

- 最坏情况O(n²)   --> 数组完全逆序
- 最好情况O(n)    --> 数组已有序
- 平均情况O(n²) 
- 空间复杂度 O(1) -->原地排序
