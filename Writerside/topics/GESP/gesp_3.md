# GESP 3级

## 1.数据编码 （原码、反码、补码）
考点解读:
理解计算机中数值的二进制表示方式，包括原码（符号位+绝对值）、反码（符号位不变，其余位取反）、补码（反码+1，用于简化加减法运算）。

需掌握三者间的转换规则及其应用场景（如补码用于表示负数）。

0.先将数值转换成2进制的表示形式，原反补码均是对于2进制的表现形式来说的。<br/>
1.原码反码补码三种表示方式均由符号位和数值位两部分组成。符号位为第1位(0为正号，1为负号)，后面的均为数值位。<br/>
[+1] = [0000 0001]原;[-1] = [1000 0001]原; 以十进制值转换成转换成8位二进制为例子。<br/>
2.正数的原反补码均一样。只有负数，他的原反补需要进行推导来求出。<br/>
3.负数的反码为原码的符号位不变，其余各位按位取反。补码为反码+1。<br/>
[+1] = [00000001]原 = [00000001]反; [-1] = [10000001]原 = [11111110]反;<br/>
[+1] = [00000001]原 = [00000001]反 = [00000001]补; [-1] = [10000001]原 = [11111110]反 = [11111111]补<br/>
4.8位二进制数能表示的十进制数的范围为-128~127;
5.特殊情况记住:以8位2进制为例:原码0可以是0000 0000或1000 0000；反码0可以是0000 0000或1111 1111；只有补码的0的表示才是唯一的:0000 0000<br/>
6.为啥补码的0的表示方式就一个？因为1000 0000是补码中特殊的编码，当作-128了。（补码统一了加减法运算，避免 -0 的二义性，并扩展负数范围（8 位补码范围：-128 ~ 127）(可不记住原理，只记住最终结论)

一些题目中会出现的专业术语:
1.“真值”：“补码的真值”指的是补码所表示的实际数值（即人类直观理解的十进制数）；机器数对应的实际数值（如 10000011 的真值是 -3，而非形式值131）；<br/>
2.“机器数”:指数值在计算机内部的二进制表示形式。<br/>
1和2的关键区别:机器数是“表象”（二进制编码），真值是“本质”（人类理解的数值）。例如：

机器数 00000101 → 真值 +5<br/>
机器数 11111011 → 真值 -5（补码表示）

# GESP 三级 - 位运算核心知识点总结

| **运算符** | **符号** | **运算规则**                                                                 | **应用场景**                                       | **示例**                                                                 |
|------------|---------|-----------------------------------------------------------------------------|------------------------------------------------|--------------------------------------------------------------------------|
| 按位与     | `&`     | 有 0 则为 0，两个都是 1 才是 1（逐位比较）                                    | - 掩码操作（提取/屏蔽特定位）<br/>- 判断奇偶性（`n & 1 == 0` 为偶数） | `5 & 3` → `1`（二进制 `101 & 011 = 001`）<br/>`if ((a & 1) == 0) // a 是偶数` |
| 按位或     | `|`     | 有 1 则为 1，同时为 0 才是 0（逐位比较）                      | - 设置某些位为 1（如标志位）                                                 | `5 \| 3` → `7`（二进制 `101 \| 011 = 111`）<br/>`num \| 0b0011 // 设置低 2 位为 1` |
| 按位异或   | `^`     | 相同为 0，不同为 1（逐位比较）<br/>特性：`a ^ a = 0`，`a ^ 0 = a`，`a ^ b ^ b = a` | - 交换两个变量的值（无需临时变量）<br/>- 简单加密（异或密钥）<br/>- 切换某一位  | `5 ^ 3` → `6`（二进制 `101 ^ 011 = 110`）<br/>`a ^= b; b ^= a; a ^= b // 交换 a 和 b` |
| 按位取反   | `~`     | 0 变 1，1 变 0（基于补码计算，结果为负数时需转换）                            | - 清除特定位（配合掩码）                                  | `~5` → `-6`（补码表示）<br/>`num & ~0b0100 // 清除 num 的第 3 位（从右往左数第 4 位）` |
| 左移       | `<<`    | 各二进制位向左移动指定位数，右侧补 0<br/>等价于乘以 $2^n$（$n$ 为移动位数） | - 快速计算 2 的幂次方或倍数                               | `5 << 1` → `10`（$5 \times 2^1$）<br/>`1 << 3` → `8`（$2^3$）           |
| 右移       | `>>`    | 各二进制位向右移动指定位数<br/>- 正数：左侧补 0<br/>- 负数：左侧补 1（保持符号）<br/>等价于除以 $2^n$（向下取整） | - 快速计算除以 2 的幂次方（向下取整）                          | `5 >> 1` → `2`（$5 / 2^1$ 向下取整）<br/>`-5 >> 1` → `-3`（补码表示）     |

常见“位技巧”模板

| 目标 | 公式 | 说明 |
|------------|------------------|------------------------|
| 取第 k 位 | `(n >> k) & 1` | 右移到最低位后与 1 相与 |
| 置 1 第 k 位 | `n |= (1 << k)` | |
| 清 0 第 k 位 | `n &= ~(1 << k)` | |
| 翻转第 k 位 | `n ^= (1 << k)` | |
| 判断奇偶 | `n & 1` | 结果 0 → 偶，1 → 奇 |
| 低位快速乘 / 除 2<sup>k</sup> | `n << k`<br/>`n >> k` | 左移乘，右移除 |

精选真题选择题:<br/>
题目1：设 unsigned x = 0xF0F0;，表达式 x & 0x0FF0 的结果为<br/><br/>
A. 0xF0F0 B. 0x00F0 C. 0x0F00 D. 0xFF00<br/><br/>
答案：C<br/>
解析：
```C++
x      = 1111 0000 1111 0000
mask   = 0000 1111 1111 0000
AND    = 0000 1111 0000 0000 = 0x0F00
```
【出自：24 年 6 月选择题 3】

题目2:要把变量 n 的第 5 位（从 0 开始计）清 0，可使用下列哪条语句？<br/>
A. n &= ~(1 << 5); B. n |= ~(1 << 5);
C. n ^= ~(1 << 5); D. n |= (1 << 5);<br/>
答案：A
解析：1<<5 得掩码 0x20，取反后第 5 位为 0，其余位 1；与运算可清 0 指定位。

题目3. 【位运算 · 真题】<br/>
题目：对于正整数 n，下列哪行代码可以快速判断 n 是否为 2 的整数次幂？<br/>
A. !(n & (n-1)) B. (n | (n-1)) == 0
C. (n ^ (n-1)) == 1 D. (n & (n+1)) == 0<br/>
答案：A<br/>
解析：若 n 为 2 的幂，则只有一个 1；n-1 把该 1 变成 0 且低位全 1，与运算结果为 0。<br/>
【出自：23 年 12 月选择题 6】

``
<br/>

题目6. 【位运算】<br/>
题目：以下哪一行代码可以交换 x、y 两整数而不使用临时变量？<br/>
```C++
A. x = x + y; y = x - y; x = x - y;
B. x ^= y; y ^= x; x ^= y;
C. x = (x & y) | (x & ~y);

```
答案：B<br/>
解析：三次异或交换经典 trick；A 有溢出风险。

题目7. 【位运算 · 真题】<br/>

## 5.数据结构（C++一维数组）
python中用的列表，列表里面元素变量类型可以不同，但是在C++中需要变量类型一致。
```C++
写法标准:
1. 定义时：
注：数组长度只能是大于0的整数，且不能是变量和变量表达式
int a[5];   // 可以
int a['0']; // 也可以！ 这里面他本质上是将'0'隐式转换成了对应的ASC2编码值48了，该式等价于int a[48]!
int a['A']; // 也可以！ 这里等价于int a[65];
int n = 5;
int a[n];   // 不可以，因为n是变量了
int a[n+2]; // 步可以，因为n是变量表达式了

2.初始化：
int a[5] = {98,88,85,78,92};    // 可以
int a[5] = {98,88,85,78,92,11}; // 不可以，最后一个元素11写在a数组的控制范围之外了。

3.获取数组中某个元素时:
int a[5] = {98,88,85,78,92}; 
cout << a[0];   // 返回98
cout << a[-1];  // python会返回序列最后一个元素，但C++不会！，编译不会出错，但运行时会给你一个意想不到的值
cout << a[99];  // 下标为负数和超过数组长度统称下标越界。编译不会出错但运行时会给你一个意想不到的值

4.赋值时:
int a[5] = {};
a = {1,2,3,4,5};    // 错误！数组名不是变量，不能通过数组名去直接给数组赋值
a[0] = 1;
a[4] = 9;   // 这两行可以

5.小tips:
数组的值会随着定义的位子不同而不同。
如果是:
int a[5];
int main(){...} // 此时a里面有5个元素，值均是0

int main(){int a[5];...}    // 此时a数组里面是该片内存遗留的垃圾数据（不推荐这么些！）
```
