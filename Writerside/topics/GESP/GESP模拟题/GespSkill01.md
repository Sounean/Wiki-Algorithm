# Gesp三级大题技巧总结

## 1.大题第一大题

他考纲就限定死了大题考一维数组！所以肯定题目是在一维数组里面进行找特殊的值！全部题型，最终只会分成以下两种:

### 1.1。找一个特殊值的题或者边遍历边处理数组的题：

在数组中找到某个特殊要求的值，然后对数组进行处理
```C++
对数组a[num]:
for(int i=0;i<num;i++){
    //  去寻找特殊要求的值
}
// 对数组进行处理
```

如副本2412的大题1：思路：遍历去求最大值、最小值(或者用sort去耍赖求最值)，然后对数组进行处理，最后输出。<br/>
如副本2409的大题1：思路：题中要满足存在序列t，以t为分界线的所有左边的元素(包括t)，的和要等于t右边的和，则输出yes。那么就是遍历这个数组，
然后在每次循环中去计算从开头一直到t的和，来看是否是数组总和的一半，是一半，则是符合的<br/>
如副本2406的大题2：思路：求数组是否存在一个数是所有元素的倍数。那么就直接sort去求最大值先。然后遍历数组，去每个元素比过去，看下是否余数为0即可<br/>
如B3868:思路：是属于边遍历边处理的问题，直接for循环遍历拿到的数组，然后根据条件处理即可。<br/>


### 1.2.找多个特殊值的题：

对a数组，自己数组内两两元素全部比较过去，求最值或者符合条件的值。
这种情况下，怎么有序且不重复的把所有该数组中任意两个元素依次可以遍历对比过去呢？用以下公式:
```C++
有数组a[num]：
for (int i = 0; i < num; ++i) {
        for (int k=i+1;k<num;k++) {
            // a[i]和a[k]的处理
            }
        }
    }
```

如题P5728 (别管什么用两个数组什么数组的，能有最狡猾的就用最狡猾的 ٩(ˊᗜˋ*)و)
如副本2403的大题2：思路：因为他是需要对a数组找出任意两个元素的，就用这个公式，在处理中，去判断是否有满足条件的。
