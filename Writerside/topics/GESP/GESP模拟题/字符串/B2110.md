# B2110 找第一个只出现一次的字符

## 题目描述

给定一个只包含小写字母的字符串，请你找到第一个仅出现一次的字符。如果没有，输出 `no`。

## 输入格式

一个字符串，长度小于 $1100$。

## 输出格式

输出第一个仅出现一次的字符，若没有则输出 `no`。

## 输入输出样例 

### 输入 

```
abcabd
```

### 输出 

```
c
```

## 输入输出样例 

### 输入 

```
aabbcc
```

### 输出 

```
no
```


## 分析

这题非常的好，难度也适中，因为他这里创建数组的思想可以包含了一类题的解法：<br/>
题目要求找出字符串中第一个只出现一次的字符，如果没有则输出"no"。

解题关键点：

需要统计每个字符出现的次数<br/>
需要按照原字符串顺序查找第一个只出现一次的字符<br/>
字符串只包含小写字母，可以用数组记录频次， --> 下标为0的元素代表a出现的次数，下标为1的元素代表b出现的次数以此类推<br/>
具体思路：

1.使用一个长度为26的数组，记录每个小写字母出现的次数<br/>
2.第一次遍历字符串，统计每个字符出现的频次<br/>
3.第二次遍历字符串，找到第一个频次为1的字符即为答案<br/>
4.如果遍历完都没有找到频次为1的字符，输出"no"  ---> 一个bool变量flag，如果中间有找到频率为1的，则把这个改成true，若没有则最终值依旧为false<br/>
