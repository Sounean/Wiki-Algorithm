# B2120 单词的长度

## 题目描述

输入一行单词序列，相邻单词之间由 $1$ 个或多个空格间隔，请对应地计算各个单词的长度。

注意：如果有标点符号（如连字符，逗号），标点符号算作与之相连的词的一部分。没有被空格间开的符号串，都算作单词。

## 输入格式

一行单词序列，最少 $1$ 个单词，最多 $300$ 个单词，单词之间用至少 $1$ 个空格间隔。单词序列总长度不超过 $1000$。

## 输出格式

依次输出对应单词的长度，之间以逗号间隔。

## 输入输出样例 

### 输入 

```
She was born in 1990-01-02  and  from Beijing city.
```

### 输出 

```
3,3,4,2,10,3,4,7,5
```

## 分析
首先读取一整行输入的字符串，包含单词和空格 --> 用getline()，用cin的话碰到空格和回车就被截止了<br/>
遍历字符串的每个字符： --> for(int i=0;i<str.length();i++){} <br/>
  遇到非空格字符时，累加当前单词长度<br/>
  遇到空格字符时，如果前面有单词（长度不为0），则输出该单词长度<br/>
最后需要输出最后一个单词的长度<br/>
注意输出格式：用逗号分隔每个长度，第一个数字前不加逗号<br/>
