# B4262 [GESP202503 三级] 词频统计

## 题目描述

在文本处理中，统计单词出现的频率是一个常见的任务。现在，给定 $n$ 个单词，你需要找出其中出现次数最多的单词。在本题中，忽略单词中字母的大小写（即 `Apple`、`apple`、`APPLE`、`aPPle` 等均视为同一个单词）。

请你编写一个程序，输入 $n$ 个单词，输出其中出现次数最多的单词。

## 输入格式

第一行，一个整数 $n$，表示单词的个数；

接下来 $n$ 行，每行包含一个单词，单词由大小写英文字母组成。

输入保证，出现次数最多的单词只会有一个。

## 输出格式

输出一行，包含出现次数最多的单词（输出单词为小写形式）。

## 输入输出样例 

### 输入 

```
6
Apple
banana
apple
Orange
banana
apple
```

### 输出 

```
apple
```

## 说明/提示

对于所有测试点，$1\leq n\leq 100$，每个单词的长度不超过 $30$，且仅由大小写字母组成。


## 分析
这题如果要比较出来出现次数最多的，那么至少需要两个数组，一个是存储字符串用的strList，一个是存储字符串出现的次数的countList。还有一个int变量要用来
记录当前是存到数组多少的下标了，即当前有多少个不同的字符串。

1.把获取来的字符串先通过自定义函数toLowerStr去转换成纯小写;<br/>
2.转换成小写后，对比strList中有没有它，有则把对应的次数数组中的值+1；，没有则更新数据;<br/>
3.获取完之后，比较出countList中值最大的，即字符串出现次数最多的，输出即可。<br/>
