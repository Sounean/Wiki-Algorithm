# P1307 数字反转

## 题目描述

给定一个整数 $N$，请将该数各个位上数字反转得到一个新数。新数也应满足整数的常见形式，即除非给定的原数为零，否则反转后得到的新数的最高位数字不应为零（参见样例 2）。

## 输入格式

一个整数 $N$。

## 输出格式

一个整数，表示反转后的新数。

## 输入输出样例 

### 输入 

```
123
```

### 输出 

```
321
```

## 输入输出样例 

### 输入 

```
-380
```

### 输出 

```
-83
```

## 说明/提示

**【数据范围】**

$-1,000,000,000\leq N\leq 1,000,000,000 $。

noip2011 普及组第一题

## 分析

这种问题模拟现实生活问题/数学问题的编程题，不要畏惧！<br/>
就是把现实生活是怎么算的，给折算到现在应该怎么算的，去搞就行。<br/>

现实生活要去写，那就是有负号就先把负号加上去；然后从数字右边往左边看，最右侧是0的就跳过，直到不是0的就开始一个个照着写下来。<br/>

所以总结我们去写的时候：<br/>
1.先判断这个数是否小于0，小于0就到时候输出先输出一个负号;  --->  用一个bool变量去存储是否小于0<br/>
2.用%10可以得到最右侧数字；用/10可以去掉最右侧数字。直到原来的值变成0了，那就结束循环。     --->  直到...结束，那就用while循环，<br/>
3.存储的值从头往后输出即可。

## 代码修改

以下代码在负数的情况是错误的，思考为什么并修改。（不要自己纯看代码！看不出问题的，打印每次获取的内容！）

```C++
#include "iostream"
using namespace std;

int num[1500];
int effectiveNum;   // 代表当前已经放了几个有效的数进去
int main(){
    // 1.获取数字
    int n = 0;
    cin >> n;
    bool flag = false;  // true表示输入的数大于0，false表示小于0
    if (n>0){
        flag = true;
    }

    bool panduan0 = true;  // 表示最右侧是否是连续的0 true表示是，false表示不是了

    // 2.把数字从右往左获取到effectiveNum数组中去(在这一步中，会去掉最右侧的连续0)
    while (n!=0){
        int geWei = n%10;   // 求出最右侧的数字
        if (!panduan0){
            // 当开始不是0了，就开始记录进数组中去
            num[effectiveNum] = geWei;
            effectiveNum++;
        } else{
            if (geWei!=0){
                panduan0 = false;
                num[effectiveNum] = geWei;
                effectiveNum++;
            }
        }
        n = n/10;   // 去掉最右侧的数字
    }

    // 3.输出结果
    if (!flag){
        cout << "-";
    }
    for (int i=0;i<effectiveNum;i++) {
        cout << num[i];
    }

    return 0;
}
```
