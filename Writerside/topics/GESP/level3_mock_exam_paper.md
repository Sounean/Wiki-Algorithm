# 3.1 编程题1 {id="3-1-1_1"}

- 试题名称：数字统计

时间限制：1.0s

- 内存限制：128.0 MB

# 3.1.1 问题描述

小杨想统计1到N（包含1和N）中，有多少个数字的各位数字之和等于给定的值S。

例如：N=20，S=5，那么满足条件的数字有：5（5=5）、14（1+4=5）、23（2+3=5，但23>20，不在范围内）。

编写程序，输入两个正整数N和S，输出满足条件的数字个数。

# 3.1.2 输入描述

总共2行。第一行一个正整数N，第二行一个正整数S。

保证 1 ≤ N ≤ 1000，1 ≤ S ≤ 27。

# 3.1.3 输出描述

一行一个整数，表示满足条件的数字个数。

# 3.1.4 特别提醒

在常规程序中，输入、输出时提供提示是好习惯。但在本场考试中，由于系统限定，请不要在输入、输出中附带任何提示信息。

# 3.1.5 样例输入1

```C++
20
5
```

# 3.1.6 样例输出1

```C++
2
```

# 3.1.7 样例解释1

1到20中，各位数字之和等于5的数字有：5（5=5）、14（1+4=5），共2个。

# 3.1.8 样例输入2

```C++

10
```

# 3.1.9 样例输出2

```C++

```

# 3.2.1 问题描述

编写程序，输入一个字符串，输出所有连续数字的和。

# 3.2.2 输入描述

一行，一个字符串，长度不超过1000，字符串中可能包含字母、数字和其他字符。

# 3.2.3 输出描述

一行一个整数，表示字符串中所有连续数字的和。如果字符串中没有数字，输出0。

# 3.2.4 特别提醒

在常规程序中，输入、输出时提供提示是好习惯。但在本场考试中，由于系统限定，请不要在输入、输出中附带任何提示信息。

```C++
abc123def45ghi6
```

# 3.2.6 样例输出1

```C++

```

# 3.2.7 样例解释1

字符串中的连续数字有：123、45、6，它们的和是123+45+6=174。
